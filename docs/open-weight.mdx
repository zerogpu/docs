Open-weight models ship with published weights and permissive licenses, so you can inspect them, self-host them, and avoid lock-in to a closed vendor. ZeroGPU serves six of them — for reasoning, coding, agentic workflows, high-volume summarization, and safety classification — through the same OpenAI-compatible API as every other model in the [catalog](/docs/model-catalog).

Full request and response examples live on the [Text Generation](/docs/text-generation) page, except `llama-guard-4-12b`, which is documented under [Moderation](/docs/moderation).
