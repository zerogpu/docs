title: "How it works"
description: "You choose the model. ZeroGPU orchestrates the compute."
---

ZeroGPU connects your application to a global network of participating edge devices, servers, and cloud infrastructure. You access models through an API while ZeroGPU manages where supported workloads run.

<Steps>
  <Step title="Choose a model">
    Pick a model from the [catalog](/docs/model-catalog) that fits your task. Use specialized models for classification, extraction, moderation, and tool selection, or explore models for text generation, reasoning, audio, and video understanding.

    Each model's documentation describes its supported inputs, endpoints, and capabilities.
  </Step>
  <Step title="Send your request">
    Call the model's supported endpoint with your API key, model ID, and input. Use an OpenAI-compatible SDK or make an HTTP request directly.

    Your application specifies the model. ZeroGPU handles the infrastructure needed to serve it.
  </Step>
  <Step title="ZeroGPU routes the workload">
    For workloads supported on the edge, orchestration evaluates compatible devices based on availability, capacity, current load, and geographic location.

    With devices distributed globally, ZeroGPU can bring inference closer to where requests originate. This helps reduce network latency while matching workloads to compute that can run them efficiently.

    Routing considers both proximity and execution capacity to support responsive inference.
  </Step>
  <Step title="Receive your result">
    The model runs on supported infrastructure and returns its output through the API. Depending on the model and endpoint, this may be generated text, structured data, embeddings, or audio, with streaming available where supported.

    Execution options vary by model. Edge devices contribute available compute, while servers and cloud infrastructure support other workloads and fallback where available.

    Use the [ZeroGPU dashboard](https://platform.zerogpu.ai) to inspect requests and monitor usage, latency, and errors.
  </Step>
</Steps>

## The network behind your API

Participating devices contribute computing capacity that would otherwise sit idle. ZeroGPU coordinates that capacity across locations and hardware, turning distributed resources into an accessible network for AI inference.

You build the application. ZeroGPU brings the compute together.
