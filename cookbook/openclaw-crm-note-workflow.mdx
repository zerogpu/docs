This guide shows how to turn a messy sales call note into a clean CRM record using the ZeroGPU OpenClaw plugin. From a single natural-language prompt, the OpenClaw agent redacts PII, extracts the contact and next step as JSON, classifies the deal stage, and writes a one-line summary. Each step shells out to the local `zerogpu` CLI instead of your frontier model, so the routine text work runs on small purpose-built models and the agent reports a real dollar figure for what the offload saved. By combining OpenClaw's skill system and ZeroGPU, this guide walks you through a practical pattern for cleaning high-volume records without provisioning any infrastructure.

For the full reference, see the [OpenClaw plugin integration guide](/integrations/openclaw).

In this guide, you'll explore:

- **OpenClaw**: An agent runtime with a plugin system of named skills. The agent auto-invokes a skill when your request matches its description, and skills run locally by shelling out to a command-line tool through the agent's Bash tools, so there is nothing to host or expose to the network.
- **ZeroGPU**: An ultra-fast, compute-efficient inference provider for apps and agents. We run purpose-built small and nano language models across an edge-powered network for the high-volume, purpose-specific tasks your app or agent runs constantly. Plug in our OpenAI-compatible API and you're live - zero GPU infrastructure, serverless, auto-scaling by default.

This setup not only demonstrates a practical application of local, low-cost inference inside an agent, but also provides a flexible pattern you can adapt to other real-world scenarios requiring high-volume text cleanup and structuring.

## 📦 Installation

The plugin's skills shell out to the `zerogpu` CLI, so install the CLI first, then install the plugin into OpenClaw:

```bash
# Install the ZeroGPU CLI (skills shell out to it)
npm install -g zerogpu-cli

# Install the plugin
openclaw plugins install zerogpu-openclaw-plugin
```

To pin a release, install a specific version with `openclaw plugins install zerogpu-openclaw-plugin@1.4.0`. Everything runs locally through the CLI, so there is no MCP server to run and no HTTP client to wire into your code.

## 🔑 Setting Up API Keys

You'll need a ZeroGPU API key and Project ID so the CLI can authenticate. Signing in once persists both to your config file, and every skill call reuses them without re-prompting.

You can go to [here](https://platform.zerogpu.ai/dashboard) to get an API key and Project ID from ZeroGPU. The key starts with `zgpu-api-` and the Project ID (UUID) is on the project settings page.

Sign in with the CLI:

```bash
zerogpu login
```

You'll be prompted for the API key and Project ID. For CI or non-interactive setups, pass them as flags instead:

```bash
zerogpu login \
  --api-key zgpu-api-XXXXXXXXXXXXXXXXXX \
  --project-id 4ed3e5bb-c2ed-4d4a-8a66-2b161a27fd1a
```

Confirm you're signed in before running any skill:

```bash
zerogpu status
```

```text
✔ Signed in as project 4ed3e5bb… · key zgpu-api-••••••XX
```

## 🐾 Cleaning a CRM Note End-to-End with OpenClaw

_This section hands the raw note to the OpenClaw agent once and lets it chain four ZeroGPU skills into a finished CRM record._

Instead of running each command yourself, describe the whole job to the agent in plain language. OpenClaw reads the request, matches it to the plugin's skills, and shells out to the CLI for each step:

```text
Clean up this CRM note for me: redact the PII, pull out the contact and the next step
as JSON, tag the deal stage as prospecting, negotiation, or closing, and give me a
one-line summary.

"Call with Daniel Okafor (daniel.okafor@brightwave.io, +1 206-555-0147) on Tue. He
wants the enterprise quote sent to their AP team by Friday and is comparing us against
two other vendors. Card on file ends 4412. Next step: send quote + book a technical
demo for next week."
```

The agent picks four skills from your phrasing ("redact", "pull out ... as JSON", "tag", "summary") and runs each one's `zerogpu` command locally:

```text
Running ZeroGPU skills…
1. redact-pii         → zerogpu redact_pii …
2. extract-json       → zerogpu extract_json … -s '{"crm":["name::str::Contact full name",
                        "email::str::Contact email","next_step::str::Agreed next action"]}'
3. classify-zero-shot → zerogpu classify_zero_shot … -l prospecting -l negotiation -l closing
4. summarize          → zerogpu summarize …
```

Each skill returns an object of the form `{ <task fields>, model, usage, savings }`, and the agent assembles them into one clean record:

```text
🔐 Redacted note:
Call with [PERSON] ([EMAIL], [PHONE_NUMBER]) on Tue. He wants the enterprise quote sent to
their AP team by Friday and is comparing us against two other vendors. Card on file ends 4412.
Next step: send quote + book a technical demo for next week.

🧩 Extracted fields:
{
  "crm": {
    "name": "Daniel Okafor",
    "email": "daniel.okafor@brightwave.io",
    "next_step": "Send enterprise quote and book a technical demo"
  }
}

🏷️  Deal stage: negotiation (0.88)

📝 Summary:
Daniel Okafor wants the enterprise quote by Friday and is comparing vendors; next step is
to send the quote and schedule a technical demo.

💰 ZeroGPU savings so far: $0.41 (3,910 host-model tokens offloaded)
```

Every step ran on a small ZeroGPU model on your machine. The frontier model only orchestrated; it never read or generated the note's contents, so the raw PII stayed out of its context.

🎉 One prompt produced a clean, structured CRM record, and the agent reported exactly what offloading the work saved.

## 💰 The Cost Savings

The point of routing these steps through ZeroGPU is what you _don't_ spend. Ask the agent for the running total, or check it directly:

```bash
zerogpu cost-savings
```

```text
💰 ZeroGPU savings so far: $0.41 (3,910 host-model tokens offloaded)
across 4 calls · top skill: summarize ($0.17)
```

The comparison is straightforward. Each of these four tasks (redaction, field extraction, single-label classification, summarization) is a narrow, high-volume job that a frontier model can do but is expensive to run at scale. On ZeroGPU's small purpose-built models the same tasks run at roughly 100 to 1000 times lower cost per call. Across one note that's a fraction of a cent; across a CRM backfill of tens of thousands of notes it's the difference between a large model bill and a rounding error, with no GPU infrastructure to run either way.
