	`/v1/chat/completions` — the Responses endpoint (`/v1/responses`) is not
	available for this model.
</Note>

> Meta's Llama 3.2 3B Instruct, packaged by ZeroGPU for fast, low-cost summarization on edge GPUs. It shares the 131,072-token context window and the summarization pipeline of llama-3.1-8b-instruct-fast, and runs on ZeroGPU worker devices with GPU acceleration, falling back to the hybrid inference cloud when no device is available. At 3B parameters, served as a Q4_K_L quantized build, it is the lighter of ZeroGPU's two Llama summarization models.
