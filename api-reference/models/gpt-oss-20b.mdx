> OpenAI's gpt-oss-20b is an open-weight Mixture-of-Experts model with 21B total parameters (3.6B active per token), served on ZeroGPU as an MXFP4 build. It is built for summarizing complex information, answering questions from supplied context, and working through multi-step instructions, and it carries a 131,072-token context window. It runs on eligible edge GPUs with cloud fallback, which makes it the lighter and cheaper of ZeroGPU's two gpt-oss models.
